# Material de referencia del proyecto

Estas copias permiten continuar el proyecto en la nube sin depender de los archivos Downloads de la laptop.

- CursoProgramacionFuncional.zip: repositorio de ejemplos, apuntes y prácticas del curso proporcionado por el usuario.
- RequisitosProyecto.md: instrucciones originales del profesor.
- PropuestaPresentada.pdf: propuesta original presentada por el equipo.

El material se conserva sin cambios. Las reglas vigentes del usuario se encuentran en AGENTS.md: basta que un recurso esté mencionado en el curso; la interfaz tiene una excepción autorizada.

El ZIP del curso no forma parte del código compilable ni del paquete de entrega de la aplicación. Este repositorio de trabajo es privado.
